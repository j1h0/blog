[리눅스][펌] Sendmail 구축

1. Sendmail 이란?

메일시스템의 구성MUA(Mail User Agent)이용자가 메일을 보내기 위해 사용하는 프로그램을 말하며 Outlook express나 Netscape의 메신저, mailx, mtool과 간은 프로그램이 해당된다.
MTA(Mail Transfer Agent)MUA가 전송하는 메일을 외부메일서버로 전달하거나, 메일을 닫는 대상 메일서버에서는 mail을 전송받아 /var/spool/mail 디렉토리 우편함에 저장하는 프로그램을 말하며 , 대표적인 프로그램이 sendmail 이다.
MDA(Mail Delivery Agent)만약에 메일을 보내는 클라리언트와 받는 서버가 동일한 로컬 호스트라면 MTA가 작동하지 않고 mail.local 과 같은 프로그램이 구동되어 메일을 /var/spool/mail디렉토리에 분배한다.

SMTP : Simple Mail Transfer Protocol의 약어로 전자 우편 전송을 위해 만든 프로토콜이다. 이 프로토콜은 7비트 아스키데이터만 전송할수 있다. 지금 우리가 흔히 사용하는 SMTP는 ESMTP(Extended SMTP)로 8비트 코드를 처리하는 확장된 프로토콜이다.

POP3: Post Office Protocol Version3. 으로 MUA가 MTA에 접속하여 자신의 우편물을 가져오는 프로토콜이다.

Sendmail은 보안에 아주 취약한 프로그램이다. 많이 보완은 되었지만 가장 많은 공격을 받는 프로그램중의 하나이다. 시스템 관리자는 새로운 sendmail 버전이 나올때마다 적절하게 자신의 시스템을 업그레이드 시켜주는 것이 중요한 업무중에 하나라고 할 수 있겠다.

2. sendmail 설정 파일들

설정파일들내용
/usr/sbin/sendmailsendmail 데몬 실행 파일
/etc/mail/sendmail.cfsendmail 주 설정 파일
/etc/mail/host-local-domains메일을 처리할 도메인에 대한 정보 기록 파일
/etc/mail/sendmail.mcsendmail 매크로 설정 파일
/etc/mail/aliasessendmail alias 설정 파일
/etc/mail/aliases.dbsendmail alias 설정 DB 파일

/etc/mail/sendmail.cf 구성파일의 주요 내용들

Cwlocalhost메일 서버로 만들고자하느 도메인을 지정한다. 복수지정이가능 하다
Fw/etc/mail/host-local-domainssendmail.cw파일에 있는 도메인에 관하여 모두 메일 처리가 가능하다.
Djtest1.comj 뒤에 특정값을 지정하면 그 특정겂을 강제적으로 메일이 처리될 수 있도록 한다.
DMtest1.com메일을 전송할때 메일 전송자의 주소를 메일 호스트와 다르게 표시하여 전달해 주는 기능을 한다.
O MaxMessageSize=1000000메일 메시지의 최대크기(바이트)를 지정한다.
O QueueDirectory=/var/spool/mqueue메일 큐 디렉토리를 설정한다.
O Timeout.queuereturn=5d메시지가 발신자에게 반환되기 까지의 시간(여기에서는 5일로 설정)
O MinQueueAge=30m메일을 보내기전 메일큐에서 대기하는 시간을 설정
O LogLevel=9기본 로그 레벨을 설정한다.
O ForwardPath=$z/.forward,$w:$z/.forward사용자의 계정 디렉토리안에 .forward라는 파일이 존재하게 되면 메일 서버로 오는 메일들을 이 파일 안에 기록된 메일 주소로 전달해 주는 기능을 한다.

Sendmail 서비스 시작과 종료

# /etc/init.d/sendmail stop
# /etc/init.d/sendmail start

메일 접근을 제어하는 access 파일 설정예제

메일의 Relay에 대한 서버측의 방침을 적어놓은 파일이다.

RELAY : 해당 호스트에 대해 메일 릴레이를 허용하며, 다른 룰이 거부하는 경우에도 메일을 수신한다.
OK : 다른 룰이 거부하는 메일에 대해서 수신한다.
REJECT : 메일 릴레이 접근에 대해 거부하여 반송한다.
DISCARD : 메일 릴레이에 대해 거부하나 아무런 메시지도 반송하지 않는다.

# vi /etc/mail/access
localhost.localdomain RELAY
localhost RELAY
127.0.0.1 RELAY
guest@unix00.gcc.go.kr “571 메일 보내지 말라고 그랬지!!!”
g2.go.kr “550 이 도메인에서 오는 메일은 처리하지 않습니다”

# makemap hash /etc/mail/access.db < /etc/mail/access

사용자 별명을 설정하는 aliases 파일 설정 예제

# vi /etc/aliases

master: root, user00, root@kiwi.gcc.go.kr
è 별명: 실제 이메일 주소

# newaliases
/etc/aliases.db 파일을 생성하는 명령이다.

일반계정 사용자가 자신의 메일을 포워딩하기 위해 설정하는 .forward 파일 설정예제

# vi $HOME/.forward
user00@kiwi.gcc.go.kr

수신되는 모든 메일을 kiwi 시스템의 user00사용자에게로 포워딩된다. Sendmail은 기본적으로 사용자 계정 디렉토리와 그 상위 디렉토리에 대한 Group에 쓰기 권한이 있으면 .forward파일을 읽지 않는다.
