[오라클]OS 부팅시 오라클 자동 시작하기

먼저 오라클을 설치한 디렉터리로 가자. 나의 경우는 /opt/oracle/product/10.2.0/bin/ 인데 이곳에 dbstart 와 dbshut 가 있다. 이중 dbstart 를 vi /etc/rc.d/rc.local (리눅스의 초기부팅설정화일 DOS의 Autoexec.bat 같은 것)에 적어주면 부팅할 때 자동으로 오라클을 실행한다. 그러나 이렇게 하는 건 start만 가능할 뿐이다. 종료까지 하려면 스크립트파일을 작성해야만 한다. /etc/oratab 은 오라클을 자동 시작 기능을 사용할지 여부를 결정하는 파일이다. 디폴트 값은 No 인데 Yes로 바꿔주면 dbstart, dbshut 를 사용할 수 있다.
vi /etc/oratab 라고 쳐보자. 맨 아래에 나의 경우 SID 이름을 phonem 이라 주었기 때문에
phonem:/opt/oracle/product/10.2.0:N 이 있을 것 인데 문장 끝에 N 이 보일 것 이다. 이걸 Y로 고치자. phonem:/opt/oracle/product/10.2.0:Y 이렇게 말이다.
그 다음 SID를 위한 초기화 파일을 복사해야만 한다. init.ora.82420051280라는 파일이 /opt/oracle/admin/phonem/pfile/ 에 존재할 것 이다.(오라클 10 이하버전은 inito{SID_NAME}.ora.82420051280 이런식으로 초기화 파일명은 SID 이름에 따라 달라진다. 예로 만일 SID 를 test 로 했다면 inittest.ora.82420051280 가 있을 것 이다. )

※절대적으로 중요함 : 이작업을 하지 않으면 dbstartup 시 control_file에러부터 시작하여 여럿 에러 친구들을 볼수 있다. ^^;

/opt/oracle/admin/phonem/pfile/init.ora.82420051280 을
/opt/oracle/product/10.2.0/dbs/ 디렉터리로 initphonem.ora 로 rename 해서 옮긴다.

자 이제 마지막으로
su - oracle -c /opt/oracle/product/10.2.0/bin/dbstart (오라클 시작 !)
su - oracle -c /opt/oracle/product/10.2.0/bin/lsnrctl start (리스너 시작 !)
이라고 쳐서 실제로 가동되는지 test 해보자. (위의 내용을 /etc/rc.d/rc.local 에 입력하면 컴퓨터가 처음 부팅할 때 자동으로 오라클과 리스너를 시작한다. 단 리스너의 경우엔 스크립트에 입력할 때 따옴표로 묶어야 start 명령이 적용된다. 이렇게
su - oracle -c /opt/oracle/product/10.2.0/bin/"lsnrctl start")

참고) 오라클 리스너 설정법
먼저 vi /etc/services를 해서 오라클을 위한 포트를 등록해준다.
LISTENER 1521/tcp # Oracle Listener by TCP
LISTENER 1521/udp #Oracle Listener by UDP
위의 밑줄 친 부분을 추가해 주면 된다.

그리고 /opt/oracle/product/10.2.0/bin/에 있는 netmgr을 실행해서 리스너를 설정한다.(아마 디폴트 값이 있을 것이다. 그냥 사용해도 무방하다.)

이렇게 하면 /opt/orqacle/product/10.2.0/network/admin/ 디렉터리에 listener.ora 가 있을 것이다. 확인하자.
이제 마지막으로 /opt/oracle/product/10.2.0/bin/에 리스너 구동 프로그램인 lsnrctl이 있다. oracle계정으로 로그인 한 후 lsnrctl start를 쳐 리스너를 시작하자. 중지할 때는 lsnrctl stop 이다. 자 이제 외부에서 접속이 가능할 것이다.
