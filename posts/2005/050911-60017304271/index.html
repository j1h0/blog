[자바]JAVA Interface Using Purpose

인터페이스 사용상의 목적

▣ 인터페이스를 사용하는 목적 I
◈ 자바의 interface는 사용자와의 상호작용(인터페이스)을 위해서 사용한다.

▣ 인터페이스를 사용하는 목적 II
◈ 사용자에게 interface만을 공개했을 때 해당 객체가 다양한 기능을 보유하더라도 interface에 해당하는 기능만을 사용하게 할 수 있다.

▣ 인터페이스를 사용하는 목적 III
◈ interface로 작업을 제한했기 때문에 해당 객체를 잘못 사용하는 오류를 막을 수 있다.

인터페이스 원론적인 목적-예시

데이터베이스 드라이브(Driver)
◈ 썬(Sun)에서 배포한 데이터베이스 인터페이스를 각 DB 회사들이 구현하게 된다. 이렇게 구현된 클래스 라이브러리를 데이터베이스 드라이브라고 하며, DB 회사는 자신들의 데이터베이스 드라이브를 제작하고 배포하게 된다. 프로그래머 입장에서는 Sun의 데이터베이스 인터페이스와 자신이 사용할 데이터베이스의 드라이브만 있다면 해당 데이터베이스에 접근해서 작업할 수 있다.
