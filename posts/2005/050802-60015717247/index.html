[툴][펌] VMware 사용법

윈도우 운영체제에서 VMware로 리눅스 설치하다가 이걸로 포스트나 작성하자는 생각에

스샷찍어놓고는 벌써 몇달이 지나서야 작성하는군요 ㅡ.ㅡ;;

하여간 이넘의 귀차니즘이 문제라니깐 ㅎㅎㅎ

그럼 간단 사용법입니다.

■ VMware 설치.

제가 vmware홈페이지에 가봤을때는 평가판을 받는곳을 알아봤더니만 4.5.2버전은 없더군요

못찾는건지 아니면 아예 없는건지는 잘 모르겠지만 일단은 어둠의 루트로 구하셔야 할듯하군요 ^^;;

어짜피 라이센스키를 등록시키려면 어둠의 루트를 찾아봐야하는건 마찬가지인지라 ㅎㅎㅎ

가장 편한방법은 당나귀를 이용하는것이지만 속도가 좀 느리죠

현재 최신버전으로는 VMware 4.5.2 Build 8848이 최신버전입니다.

■ VMware 실행

VMware를 실행한 화면입니다.

화면 좌측에 있는 New Virtual Machine을 선택하여 줍니다.

새로운 창이 하나 뜨게 되는데 다음버튼을 클릭합니다.

설치방법은 Typical보다는 Custom이 설정할수 있는 부분이 많기에 Custom을 선택했습니다.

설치할 운영체제를 선택하는 화면입니다.

저는 데비안리눅스 사지 넷 인스톨러시디로 설치를 하기에

Ohter Linux (Kernel 2.6.X)버전을 선택하였습니다.

자신이 설치하고자 하는 리눅스를 선택하시면 되겠습니다.

설치할 운영체제의 가상디스크와 정보파일이 저장될 폴더를 지정하는 화면입니다.

원하는 폴더경로를 입력해주시고 버츄얼머신 이름을 원하시는걸로 바꿔줍니다.

이름을 바꿔주는 이유는 구별하기 쉽게 하기 위해서이지요 ㅎㅎㅎ

설치할 게스트운영체제에 메모리를 적당히 할당해줍니다.

약 절반정도 주시면 적당할것입니다.

설치할 게스트 운영체제에서 인터넷 연결을 어떻게 할것인지 선택하는 것입니다.

꼬옥 두번째 NAT를 선택하세요

설치할때 스카시모듈을 선택하는 것입니다.

그냥 디폴트 값인 Buslogic을 선택해줍니다.

새로 설치하는 것이기때문에 첫번째 것을 선택합니다.

세번째는 고급사용자에게 권장하는 방법입니다.

잘못하면 시스템 말아먹는 경우가 있으니 처음 설치하시는 분이나

익숙치 않는 분들은 처음것을 선택하고 넘어가세요 ^^;;

디스크 타입을 선택하는 화면입니다.

보통 스카시로 선택하면 되지만 가끔 리눅스에서 vmware스카시를 인식못하는 경우가있어서

저는 IDE를 주로 이용합니다.

원하시는걸 선택하세요

설치할 게스트 OS에 용량을 할당하는 화면입니다.

적당히 주시면됩니다.

단 주의할것은 용량할당하고 Allocate all disk now 이옵션을 선택하게되어버리면

할당해준 공간을 가상디스크로 잡아서 생성해버린다는 것입니다.

추천하는 방법은 아무것도 체크하지 않는 것입니다.

저 Allocate all disk now를 체크하지 않고 설치하게되면 vmware에 설치한 게스트 os는 할당해 준

용량으로 HDD를 잡지만 실제로 호스트OS에서는 게스트OS에서

사용한 만큼의 용량만 차지하게 돕니다.

잘 이해가 안되시는 분들이 있을까봐 좀더 자세히 설명을 하면

XP에 vmware를 설치해서 리눅스를 설치한다고 할때

저 Allocate all disk now 옵션을 선택하지 않고 10기가용량을 주고 설치를 하게 되면

XP에서는 리눅스에서 사용한(예를 들어 1기가만 사용했다면)용량만큼만 공간을 차지 하게 됩니다.

vmware버츄얼 디스크가 1기가의 용량으로만 생성된다는 것이지요

리눅스에서 용량이 늘어갈수록 점점 늘어나는 형식입니다.

그런데 저 Allocate all disk now를 선택하고 설치를 진행하시게되면 XP에 바로10기가의 용량의

vmware버츄얼 디스크가 생성이 되어버립니다.

이건 참 비효율 적이겠지요

HDD용량이 빵빵 하다면야 미리 용량을 잡아버려도 되지만 공간이 부족하신 분들은

저 옵션을 선택하지 않고 설치해 유동적으로 용량을 확보하시면 됩니다. ㅎㅎㅎ

vmware에서 설정한 내용을 저장하는 화면입니다.

처음에 vmware버츄얼 디스크 저장되는 곳에 같이 저장되는게 디폴트 값이니

이름을 바꿔주신분들만 이름을 수정하신뒤에 마침을 누르세요

자 이제는 설치할 준비가 된것입니다.

설치하기 전에 약간의 설정을 좀 더 하셔야 합니다. ^^;;

우선 CD롬 설정입니다.

CD로 설치하실 분은 CD-ROM을 더블클릭하시면 위와 같은 창이 뜨는데

Use physical drive항목에서 자신의 설치할 OS cd가 들어있는 cd드라이브를

선택하여 주시면 됩니다.

vmware는 iso로 설치가 가능한데 iso설치는

use iso image에 체크하시고 iso파일이 있는 경로를 지정해주시면 됩니다.

저는 데비안을 iso로 설치하기에 Use iso image를 선택한

화면 모습입니다.

사운드 장치 설정 화면입니다.

specify host sound adapter를 선택하여 줍니다.

사운드를 선택한 화면입니다.

이제는 모든 준비가 끝난 상태입니다.

이제 Start Virtual Machine을 클릭하고 진행하시면 됩니다.

VMware를 몇번 사용해왔지만

다른 운영체제를 경험하는데 있어서는 좋지만

실제 HDD에 설치하는 만큼 성능을 끌어내지 못하기에

오래 사용하지는 못하겠더군요

속도도 느리고....

그래서 저는 요즘 vmware는 거의 사용하지 않고있습니다.

새로 나온 리눅스버전이 있을때 어떻게 변했나 살펴보려고 설치했다가는

바로 지워버리고 있지요....

저같이 vmware를 이용해 다른 운영체제를 경험하고 싶으신 분들은

이 문서가 도움이 되었으면 좋겠군요

참고로 vmware를 이용해 리눅스를 설치하시는 분들에게 조언

(윈도우를 설치하시는 분들도 알고 계시면 좋을듯)

vmware는 실제 하드웨어를 게스트OS에 제공해주는게 아니라

CPU를 뺀 나머지 하드웨어는 전부 에뮬레이팅한다는 것입니다.

무슨 얘기냐 하면 자신의 그래픽카드가 라데온시리즈라 할지라도

게스트 OS에서는 vmware가 에뮬레이팅한 그래픽카드를 인식한다는 것이지요

그러니 리눅스 설치할때 모듈을 잡을때 이점을 실수하게 됩니다.

특히 젠투같은 리눅스를 설치할때 많이 범하게 됩니다.

레드햇 기반의 리눅스나 다른 버전의 배포판 리눅스는 웬만해서 알아서 잡아줍니다.

그래서 각 리눅스설치시에 알아두셔야 할 하드웨어 정보를 알려드리겠습니다.

VMware 하드웨어 모듈

네트워크 모듈(렌) : pcnet32

사운드모듈 : ens1371

그래픽모듈 : vmware or vesa(요즘은 vmware로 잡아주더군요)

이정도만 아시면 리눅스설치시(특히 젠투)문제가 없을 것입니다.

워낙에 말 주변머리 없는데다 표현을 잘 못해서

내용이 이해가 될려나 모르겠습니다.

에휴...

이상 허접스런 vmwaer 사용법 이었습니다.

작게나마 도움이 되었으면 좋겠군요....
