[델파이]프린터 직접제어 커맨드 보내기

현재 개발중인 '생물자원 바코드 시스템'에 적용시킨 내용입니다.

본 내용은 다른 여타 델파이 관련 커뮤니티에도 많은 자료가 있으니 부족하시면 참고하시기 바랍니다.

글쓴이 - 신지호

=======================================================================================

델파이를 이용하여 '생물자원 바코드 시스템'을 개발중입니다.

제가 가지고있는 프린터는 Brady라는 회사의 BP-1344라는 모델입니다.

홈페이지에 들어가보니 프린트직접제어 커맨드 매뉴얼이 있더군요..

그 매뉴얼보고.. 그리고 또 본사의 담당 엔지니어에게 자문을 구해 커맨드를 구성하였습니다.

해당 커맨드를 델파이 문법으로 구현한 부분은 아래와 같습니다. (스트링으로 처리)

printCont := #2 + 'c0010'+
#2 + 'LD11' +
'm'+
'H14_P6_S6'+
'R0000'+
'C0000'+
'2' + '1' + '11' + '000' + '0220' + '0510' + 'STRAIN NO : ' + strainNo + #13 +
'2' + 'D' + '73' + '000' + '0230' + '0370' + edtBarcode.Text + #13 +
'2' + '1' + '11' + '000' + '0220' + '0330' + 'PAY NO : ' + payNo + #13 +
'Q0010'+
'E';

//프린터마다 혹은 프린터 제조 회사마다 직접제어 커맨드가 모두 다르기 때문에 대충 몰라도 되는 내용

위의 커맨드 스트링을 이제 LPT1이나 COM1과 같은 포트로 날려야 합니다.

패러럴 포트로 PC와 직접 연결되어있다면 LPT1(~n) 포트로,

시리얼 포트로 연결되어있다면 COM1(~n)포트로 커맨드를 보내는게 일반적이지만

프린터나 프린터를 구성하고 있는 PC에 따라서 그 포트의 설정은 다소 차이를 보일수 있습니다.

자 이제 bcM.pas라는 파일을 알아보야야 합니다. 내용은 아래와 같습니다.

{***********************************
DESC : 프린터 직접 제어 모듈
Author : theman (_kissme_@daum.net)
Sinse : 2005. 12. 19
************************************}

unit bcM;

interface

uses
Windows, Messages, SysUtils, Variants, Classes, Graphics, Controls, Forms, Dialogs;

procedure OpenPort(Port : String);
procedure DataSend(P : String);
procedure ClosePort;

implementation

var
F : TextFile;

procedure OpenPort(Port : String);
begin
try
Assignfile(F, Port);
Rewrite(F);
except
ShowMessage('포트 접근이 안됩니다.');
end;
end;

procedure DataSend(P : String);
begin
try
Writeln(F, P);
except
ShowMessage('패킷을 전송 할 수 없습니다.');
end;
end;

procedure ClosePort;
begin
try
CloseFile(F);
except
ShowMessage('포트를 닫는데 실패했습니다.');
end;
end;

end.

별거 없이 정말 간단합니다.

총 3개의 프로시져로 구성되어있습니다.

위의 소스를 긁어서 직접 개발되는 유닛에 붙여넣으셔서 사용하셔도 무방합니다.

프로시져의 내용을 보면,,,,

OpenPort : 해당 포트를 오픈하는 프로시졉니다.

LPT1에 보내실거면 프로시져의 인자에 스트링 형으로 'LTP1'이라고 입력한 후

호출하시면 됩니다.

DataSend : 프로시져의 인자로 위에 구성한 커맨드(printCont)를 입력한 후 호출하면 됩니다.

ClosePort : 해당 포트를 닫는 프로시져 입니다.

자세한 구성방법은 bcM.pas의 소스를 찬찬히 살펴보시면 전혀 어려운것 없이 이해가 될 것입니다.

자 이제 프린터로 직접제어 커맨드를 날리는 부분은 아래와 같습니다.

bcM.OpenPort(printPort); //포트오픈

bcM.DataSend(printCont); //직접제어 커맨드를 해당 프린터 포트로 보내는 부분
bcM.ClosePort; //포트해제(닫기)
