[델파이] [펌] [활용] DB에 GIF,JPG등 이미지집어넣고쓰기

[팁] DB에 Gif,JPG이미지를 넣어 사용하기.

팁을 올리기 전에 먼저 잡담 한마디.. 델파이 질답란에 가서
보면 가끔 답답할때가 있습니다. 어떤 문제에 대한 해결을 자
신이 하려는 최소한의 노력도 없이 질문부터 올리는 글들이
너무 많은것 같습니다. 요즘은 '같이 해결해 볼까하고'하는
생각이 드는 질문들이 너무 없는것 같습니다. 질답란에서
LT치기 그리어려울까요? 델파이책이 그리도 많은데 서점에 서
서 한번 찾아보는게 그리 어려울까요? 에구, 어차피 답변도
잘 안올리는 저같은놈이 할말은 없습니다만, 그냥 넉두리였
습니다. 델마당에 못 가는 죄로 델마당 회원의 의무를 다하고
저 팁을 한번 올려봅니다. 질답란에 질문은 있었는데 답변이
없었던 것이기도 하구요. 그래서 고수님들에겐 별거 아니겠지
만 질문의 답변삼아...(이런, 팁보다 잡담이 더 길겠다.)

우선 BlobField는 어떤 바이너리 형태의 데이타도 집어 넣
을 수 있다는건 누구나 다 아는 사실일겁니다. 이건 Stream
이라는 메모리 관련 객체를 통해 보통 다루지요. BlobField
를 다루기 위해서는 DataSet에서 제공하는 CreateBlobStream
이라는 함수를 이용하여 Stream을 얻어 사용합니다. 즉
var BStream : TStream
begin
BStream := Table1.CreateBlobStream(
Table1.FieldByName('Graphic'),
bmReadWrite);
이런식으로 Stream을 열어 여기에 쓰면 바로 DB에 쓰는 것과
같이 되는 것입니다.

그럼 이미지를 DB에 Write하는 문장부터 보겠습니다. 먼저
Gif이미지는 RXLib의 TGifImage를 사용하고 JPeg는 델3에 기
본적으로 제공하는 TJPegImage를 쓰겠습니다.

var BStream : TStream;
begin
Table1.Edit;
BStream := Table1.CreateBlobStream(Table1Graphic,bmWrite);
try
if (Image1.Picture.Graphic is TBitMap) then begin
(Image1.Picture.Graphic as TBitmap).SaveToStream(BStream);
end else if (Image1.Picture.Graphic is TGifImage) then begin
(Image1.Picture.Graphic as TGifImage).SaveToStream(BStream);
end else if (Image1.Picture.Graphic is TJPegImage) then begin
(Image1.Picture.Graphic as TJpegImage).SaveToStream(BStream);
end else ShowMessage('나머지는 귀찮다!! 알수 없는 이미지');
finally
BlobStream.Free;
end;

위와 같은 방식을 사용하여 TImage에 불러들여진 어떤 이미지 파일도
저장이 가능하게 됩니다. 하지만 비트맵의 경우 기존 BlobField에 저
장하는 방식과 다르기때문에 DBImage로 보실 수가 없게됩니다. DBIm
age에 띄우려면 보기좋게 에러를 내벴겠지요. 간단하지 않습니까? 그럼
이미지를 다시 불러 와야겠지요. 다음을 보겠습니다.

var BStream : TStream;
AG : TGifImage;
AJ : TJPegImage;
AB : TBitmap;
Data : array[0..15] of Char;
begin
BStream := Table1.CreateBlobStream(Table1Graphic,bmRead);
try
BStream.Read(Data,16);
BStream.Position := 0;
if(Data[0]='G')and(Data[1]='I')and(Data[2]='F') then
{너 Gif냐! 나 TImage야! 그럼 타악!! 읽는거야 로딩 될때까지!! ^.^}
begin
AG := TGifImage.Create;
try
AG.LoadFromStream(BStream);
Image2.Picture.Assign(AG);
finally
AG.Free;
end;
end else if(Data[6]='J')and(Data[7]='F')and
(Data[8]='I')and(Data[9]='F') then
begin
AJ := TJPegImage.Create;
try
AJ.LoadFromStream(BStream);
Image2.Picture.Assign(AJ);
finally
AJ.Free;
end;
end else begin
{Bitmap은 처음 Data[0]에는 'B',Data[1]에는 'M'이
들어가거든요.. 하지만 정확한 방법은 아님 다른 이
미지들도..}
AB := TBitmap.Create;
try
AB.LoadFromStream(BStream);
Image2.Picture.Assign(AB);
finally
AB.Free;
end;
end;
finally
BStream.Free;
end;

음.. 쓸데없이 코딩이 길어졌습니다. 델파이에 TImage는
화일 확장자 없이 내용만으로 이게 무슨 형태의 이미지인
지 모릅니다. 결국 가장 쉬운 위의 방법으로 이게 무슨 형
태의 파일인지 알아내서 해당 형태의 이미지로 로딩을 하
는겁니다.(맘에 안들지만 가장 쉬우니..쩝) 이런방식 말고
도 필드를 하나 더두어 이것이 어떤 형태의 이미지인지 저
장해 둔다면 더 간편하게 쓰실 수 있겠지요.
보시다시피 Stream을 이용하여 이미지파일을 DB에 기냥
구겨 넣어 버리는 형태입니다. TImage로 불러들일 수 있는
형태의 화일은 모두 DB화 시킬 수 있다는 것이지요..
팁이라할 가치가 있을지 모르겠지만... 도움이 되시길
빌겠습니다. 탁이가..
