[오라클]ORA-12560: TNS:프로토콜 어댑터 오류

BASE : LINUX 9 Fedora4

Database : Oracle 10.2.0.1

위의 에러는 오라클 데이터베이스나 SQL*PLUS문제가 아니다

아마도 OS에 설치된 firewall때문이다.

linux 자체 firewall이라면

해당 파일을 열어 LISTENER:1521을 추가하면 되고

X(그놈, KDE)가 설치되어있다면 GUI로 설정이 가능하다.

X 상에서 설정방법----

상단의 데스크탑-시스템도구-보안수준-TCP:1521을 추가하면 된다.
