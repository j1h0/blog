[오라클] role을 이용하여 user에게 권한주기

Oracle에서 기본적으로 제공되는 Role은 3가지이다.

connect, resource, dba

DBA로 사용할 유저 dbauser와 DBA 계정이 없는 유저 opuser를 만든다면

dbauser에게는 dba role을 부여하고 (sys 권한이 필요한 작업외의 모든 작업 가능)

opuser에게는 reource, connect role과 그외에 필요한 권한을 별도로 부여한다.

ex)

-- dba 권한 user 만들기

create user dbauser identified by passwd
default tablespace TBS1
temporary tablespace temp;

grant dba to dbauser;

-- 일반사용자 만들기

create user opuser identified by passwd
default tablespace TBS2
temporary tablespace temp;

grant select any table to opuser ;
grant insert any table to opuser ;
grant update any table to opuser ;
grant delete any table to opuser ;
grant create session to opuser ;
grant connect,resource to opuser ;
grant select any dictionary to opuser ;

※ 8i까지의 버젼에서는 any table 에 dictionary table도 포함되었으나

9i이후에서는 dictionary를 볼수있는 별도의 권한이 생성되었다.

권한을 주지 않으면 물론 dictionary를 볼 수 없다.
