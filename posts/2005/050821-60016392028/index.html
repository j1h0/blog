oracle 9.2.0 설치
Oracle 9i R2(9.2.0.1) 설치를 위한 선행 작업
1). Linux 커널 설정 ← root 계정
- 현재 linux에 설정되어 있는 공유 메모리 세그먼트의 최대 크기(shmmax)를 확인한다.
[root@jini root]# cat /proc/sys/kernel/shmmax
33554432
- 공유 메모리 세그먼트의 최대 크기를 2048MB로 변경한다.
echo 2147483648 > /proc/sys/kernel/shmmax
cat /proc/sys/kernel/shmmax
2147483648
- 수정한 값은 일시적으로만 시스템에 적용되므로 영구적으로 시스템에 적용하기
위해서는 다음과 같은 명령어를 수행하면 된다.
echo “kernel.shmmax = 2147483648” >> /etc/sysctl.conf
ipcs ?al
--------- Shared Memory Limits ------------
max number of segments = 4096
max seg size (kbytes) = 2097151 ?? 확인
