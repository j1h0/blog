[델파이] [펌] Zoes 컴포넌트 설치하기

이 글은 2005년 8월 24일 기준으로 작성되었습니다.

델파이 7, 윈도우 XP 기준으로 작성하였습니다.

1. zeos 웹사이트 http://www.zeoslib.net 에 들어가서 Zeos Database Objects의 zeosdbo-6.5.1-alpha를 클릭하여 최신 버젼을 다운 받는다.

그림 1-1 (웹페이지의 클릭부분)

2. 다운을 받고 나면 해당 파일[zeosdbo-6.5.1-alpha.zip]을 압축 해제한다.

그림2-1 (압축 해제후 폴더 검색)

(그림 2-1에 Install.html을 보고 따라하면 되지만 그것도 귀찮은 사람들을 위하여 더 설명하겠다.)

3. (FireBird만 사용할 사람은 3번의 과정을 넘어가서 4번부터 봐도 된다.) 먼저 lib 디렉토리를 보면 MySql, postgresql등의 폴더가 있을것이다. 자기가 사용하고자 하는 데이타 베이스에 해당하는 폴더안에 DLL을 Windows\System에 복사하면 된다. - 윈도우2000 사용자는 winnt\system32 가 될것이다. (뭐 있는 거니까 쓰든 안쓰든 그냥 있는거 다 넣어도 될거 같다. ^^)

4. 이것은 그냥 참고용으로 넣어 놓았다. 실행할 필요가 없다.

이번 섹션은 그림만 보고 5번으로 넘어가면 된다.

델파이를 기동시킨후 [File] -> [Open Project...]를 클릭한후 압축을 푼 디렉토리 내부에 \zeosdbo-6.5.1-alpha\packages\delphi7 디렉토리 안에 있는 ZeosDbo.bpg (프로젝트 그룹)를 선택한다. 그럼 아래와 같은 화면이 나타난다.

그림 4-1 (Project Manager)

5. ㄱ. 또는 ㄴ. 의 방법으로 dpk파일을 연다.

ㄱ. 아래 그림 5-1에 있는 델파이 패키지 파일을 그림 4-1의 bpl 순서대로 클릭한다.

(*** 주의*** 이 순서대로 실행해야 한다.)

ㄴ. 델파이를 기동시킨 상태에서 [File] -> [Open Project...]를 클릭하고 Open Project의

파일 형식을 델파이 패키지로 변경후 압축을 푼 디렉토리인

{\zeosdbo-6.5.1-alpha\packages\delphi7} 디렉토리 안에 있는 아래의 파일을

그림 4-1의 bpl 순서대로 실행해도 된다.

    1. ZCore.bpl 2. ZParseSql.bpl 3. ZPlain.bpl 4. ZDbc.bpl 5. ZComponent.bpl <---- 1~5번의 순서대로 실행한다.

그림 5-1 (delphi 7 폴더안에 있는 dpk)

6. 5번을 실행하였을시 그림 6-1이 나타난다. Compile과 Install을 한후 다시 5번으로 돌아가 반복하면 된다.

그림 6-1 (첫번째 열어야 하는 ZCore.dpk)

7. 마지막으로 라이브러리에 해당 폴더를 추가한다. [Tools] -> [Environment Options...] -> [Library] -> [Library path]에 들어가서 소스가 있는 디렉토리들을 추가한다.

그림 7-1 ([Tools] -> [Environment Options...])

]

그림 7-2 ([Library] -> [Library path])
