[아파치＊톰캣] 웹사이트에 도메인 추가하기

1-톰캣 설정 conf/server.xml

<Service name="Catalina">

<Connector port="8009" enableLookups="false" redirectPort="8443" protocol="AJP/1.3" />

<Engine name="Catalina" defaultHost="localhost">

<Realm className="org.apache.catalina.realm.UserDatabaseRealm"
resourceName="UserDatabase"/>

<Host name="rnd.tomico.co.kr" appBase="webapps"
unpackWARs="true" autoDeploy="true"
xmlValidation="false" xmlNamespaceAware="false">

<Context path="" docBase="/home/wwwRoot/phonemap/htdocs" crossContext="true" debug="0" reloadable="true"/>
<Context path="/images" docBase="/data/phonemap/htdocs/images" />
<Alias>rnd.tomico.co.kr</Alias>
<Alias>www.qqg.co.kr</Alias> <-- 추가된 도메인
<Alias>qqg.co.kr</Alias> <-- 추가된 도메인
</Host>

</Engine>

</Service>

2-아파치 설정 추가 conf/httpd.conf

<VirtualHost 61.33.226.123:80>
ServerName qqg.co.kr <-추가되는 도메인네임
DocumentRoot /home/wwwRoot/phonemap/htdocs
ServerAlias qqg.co.kr www.qqg.co.kr <-호스트와 도메인을 분리하여 셋팅. 추가할 호스트가 있다면 이어서 추가
Alias /images/ /data/phonemap/htdocs/images/
<Directory "/data/phonemap/htdocs/images/">
Options Indexes MultiViews
AllowOverride None
Order allow,deny
Allow from all
</Directory>
</VirtualHost>
