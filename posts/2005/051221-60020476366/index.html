[MS-SQL] 한개의 인스턴스에 2개의 포트 오픈하기

=======================================================================================

본 내용은 다른 여타 MSSQL 관련 커뮤니티에도 많은 자료가 있으니 부족하시면 참고하시기 바랍니다.

글쓴이 - 신지호

=======================================================================================

대상 - Microsoft SQL Server 2000

MSSQL를 사용하는 중에 'Oracle처럼 서비스별로 리스너 포트를 따로따로 설정할 수 없는가...?' 라는 의문이 들었습니다.

그래서 MS-SQL도움말도 찾아보고 인터넷도 뒤져보고 데이터베이스 바이블 책도 찾아봤는데...

제가 못찾은 것인지... 찾을수가 없더군요..

그래서 위험을 무릅쓰고.... 상용으로 올라가있는 데이터베이스를 실험대상으로 삼았습니다.

여러가지 테스트를 한 결과 서비스별로 포트를 지정하는 방법은 아직 찾지 못했고요...

한개의 인스턴스의 기본포트(1433 port)에 또 다른 포트를 추가할수 있다는 것을 알게되었습니다.

서비스별(인스턴스별) 포트 설정방법은 또 다른 방법을 찾아봐야 할것 같습니다.

[설정방법]

1. SQL SERVER 네트워크 유틸리티를 실행합니다.

2. '일반'탭의 '사용할 수 있는 프로토콜'이라는 리스트박스가 있는데...

서버 설치시 기본으로 설치를 하셨으면 첫번째 줄에 '망명된 파이프'가 있고 두번째 'TCP/IP'가 있습니

다.

3. 'TCP/IP'를 선택하고 아래 '속성(P)'버튼 클릭!!!!

4. 속성창을 클릭하게 되면 '{SQL서버이름} - TCP/IP' 라는 제목의 속성창이 뜨게됩니다.

5. 서버 설치시 기본으로 설치를 하셨으면 기본포트가 '1433' 으로 설정되어있을것입니다.

6. 1433이라고 적혀져있는것은 그대로 두시고....

만약 12번포트를 추가로 사용하고 싶으시면 옆에 ','를 찍으시고 '12'라고 입력하시고 확인버튼!!! 클릭

7. 그러고 나서 일반탭의 '적용(A)'을 누르시면 '모든 변경내용이 저장되지만, SQL SERVER 서비스를 중지

했다가 다시 시작하기 전까지는 영향을 끼치지 않습니다.' 라는 확인창이 나옵니다.

말인 즉슨!!!!!! SQL Server를 리스타트 하라는 것입니다. ^^;

8. SQL Server를 중지했다가 다시 시작하시면 추가한 '12'번 포트가 적용되게 됩니다.

참고로... 이 Tip의 위험성이나 안정성은 여러방면으로 테스트를 해보지 못했기에 보장할 수 없습니다. ^^
