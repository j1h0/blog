안녕하세요.

smtp 포트를 변경하는 방법은 여러개가 있지만, 가장 쉬운 방법을 알려드리겠습니다.

/etc/services 파일을 열어서 보시면 smtp 를 검색해 보시면

smtp 25/tcp

smtp 25/udp

라고된 부분이 보일겁니다. 여기의 25를 사용하고자 하는 포트 번호로 변경해 주세요.

2525 정도...

smtp 2525/tcp

smtp 2525/udp

이렇게 하시면 되겠죠... 여기서 한가지 주의하실점은 만약 기존의 메일서버가 /etc/services 파일을 참조하여 포트를 설정한다면 이런 방식으로 하면 기존의 메일서버가 작동하지 않는다는 것입니다.

위와 같이 변경해 보시고 기존 메일이 제대로 전송되지 않는다면, 아래의 작업을 따라해 보세요. 위의 방법으로 둘다 문제 없이 된다면 아래부분을 일부러 손댈 필요는 없을듯 싶습니다.

# vi /etc/sendmail.cf
# SMTP daemon options
O DaemonPortOptions=Port=smtp,Addr=127.0.0.1, Name=MTA

라는 부분을 찾아서 아래와 같이 바꿔주세요.
O DaemonPortOptions=Port=2525,Name=MTA

사용자 인증을 사용하기 위해서는 아래의 부분도 수정해 주세요.

# vi /etc/mail/sendmail.mc
dnl TRUST_AUTH_MECH(`DIGEST-MD5 CRAM-MD5 LOGIN PLAIN')dnl
dnl define(`confAUTH_MECHANISMS', `DIGEST-MD5 CRAM-MD5 LOGIN PLAIN')dnl
위의 2 라인을 찾아서 앞쪽의 dnl(주석) 을 제거해 주시고,
DAEMON_OPTIONS(`Port=smtp,Name=MTA')

라는 라인을 찾아서
DAEMON_OPTIONS(`Port=2525,Name=MTA')

로 바꿔주세요

파일을 저장하고 나서 sendmail.cf 파일을 다시 만들어줘야합니다.

# m4 /etc/mail/sendmail.mc > /etc/sendmail.cf

이렇게 하시고 /etc/init.d/sendmail restart 또는 start 하시면 될겁니다.

좋은 하루 되십시오.
