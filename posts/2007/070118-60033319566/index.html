[MSSQL] 세가지 종류의 트리거를 한번에

트리거로 로그를 기록하는 방식이 바로 이전 값만을 기록하는것인가보네요..

SQL SERVER에서는 트리거처리시 단일 ROW인지 멀티 ROW인지에 따라 맞게 처리해주는 것이 중요합니다.

아래처럼 하면 여러개의 row가 들어오든 하나의 row가 들어오든 관계없습니다.

단, 원본테이블 자체가 신규테이블이라는 가정입니다.

기존에 존재하는 테이블에 트리거를 붙이는 거라면

약간의 변형이 필요하겠죠..

[하나 트리거로 세가지 상황을 처리함]

for insert, update, delete

--> 자료가 이미 있을테니 delete 표시만 : delete상황에서만 발생
update log_table
set 상태 = 'D'
from deleted d
where log_table.키 = d.키
and not exists
(select 'x'
from inserted i
where i.키 = d.키) --> delete상황에서만 발생하도록 함

--> 자료가 있으면 update : update상황에서만 발생
update log_table
set 이름 = i.이름
,번호 = i.번호
,지역 = i.지역
,상태 = 'U'
from inserted i
,deleted d
where d.키 = i.키 --> update상황에서만 발생하도록 함

--> 자료가 없으면 update : insert상황에서만 발생
insert into log_table
select 키, 이름, 번호, 지역, 'I'
from inserted i
where not exists
(select 'x'
from deleted d
where d.키 = i.키) --> insert상황에서만 발생하도록 함
