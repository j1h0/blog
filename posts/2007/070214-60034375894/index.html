[공유] 코드 자동화 - CodeDom 2

이번에는 CodeDom을 활용하는 또다른 방법으로 runtime 시에 code 를 compile 해서 사용하는 방법에 대해서 살펴 보자.

아래는 C#으로 작성한 예제이다. (.NET Framework 2.0 기준이며 1.0일때와 약간 차이가 있다.)

CodeDomProvider cdp = new CSharpCodeProvider();

CompilerParameters compilerParameters = new CompilerParameters();

compilerParameters.GenerateExecutable = false;
CodeDomProvider 클래스를 상속받은 클래스인 CSharpCodeProvider라는 객체를 생성하고

Compiler 호출시의 Parameter 값인 CompilerParameters객체를 생성해 필요한 값을 설정한다.

string[] code =
{
@"namespace CodeDomTest1 { class Class1
{

public string Test () {
return ""ok"";
}
}
}"};

compile하려는 소스코드를 작성한다. 여기서는 간단하게 Test 메소드 호출시 console에 ok를 출력하도록 했다.

CompilerResults cr =
cdp.CompileAssemblyFromSource(compilerParameters, code);

소스를 Compile한 결과를 CompilerResults에 할당한다.

if (cr.Errors.Count > 0)
{
for (int i = 0; i < cr.Output.Count; i++)
Console.WriteLine(cr.Output[i]);
for (int i = 0; i < cr.Errors.Count; i++)
Console.WriteLine(i.ToString() + ": " + cr.Errors[i].ToString());

}

Error가 있는 경우 error를 출력하도록 한다.

아래는 Reflection을 이용해 compile된 type의 Test 메소드를 호출하는 부분이다.

Assembly asm = cr.CompiledAssembly;

Type t = asm.GetType("CodeDomTest1.Class1");

object instance =asm.CreateInstance(t.FullName);

MethodInfo mi = t.GetMethod("Test");
object obj = mi.Invoke(instance, null);
Console.WriteLine(obj.ToString());

여기서는 아주 간략한 예제를 만들어서 테스트 해 보았다. CompilerParameter 로 compile시 필요한 다양한 setting 값을 설정할 수 있으므로 필요에 따라 변경해서 사용하면 된다.

runtime시에 compile 후 Reflection을 통해서 호출하는 방식이라 속도가 좀 문제가 될 것 같다.
