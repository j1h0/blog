[일괄 마이그레이션 순서]

1. GRAND_RESROUCE에 걸려있는 foreignkey Constraint를 제거한 후 마이그레이션 한다.

* FK Constraint 제거

- FK_rg_BARCODE_GRAND_RESOURCE

- FK_rg_ALLOCATE_KCTCMAIN

* 32번 KCTMAIN에서 33번 GRAND_RESOURCE로 마이그레이션한다.

* FK Constraint 생성

* 사용 프로시져

- sp_sm_MIGRATE_KCTCMAIN

★★ 1 의 일괄 작업을 MIGRATION_1.sql 로 실행하여 처리한다 ★★

##SL시리즈 관련 마이그레이션##

2. rg_DATA, rg_BARCODE, rg_ALLOCATE 에 걸려있는 foreignkey Constraint를 제거

* rg_DATA

- FK_sl_SELL_LINK_rg_DATA

- FK_sl_SELL_HISTORY_rg_DATA

* rg_BARCODE

- FK_rg_DATA_rg_BARCODE

* rg_ALLOCATE

- FK_rg_DATA_rg_ALLOCATE

3. RG Series Data Truncate

* rg_DATA

- rg_DATA -> sl_SELL_LINK, -> sl_SELL_HISTORY

* rg_BARCODE

- rg_BARCODE

* rg_allocate

- rg_ALLOCATE

4. rg_data, rg_barcode, rg_allocate에 걸려있던 foreignkey Constraint를 생성한다.

* rg_DATA

- FK_sl_SELL_LINK_rg_DATA

- FK_sl_SELL_HISTORY_rg_DATA

* rg_BARCODE

- FK_rg_DATA_rg_BARCODE

* rg_ALLOCATE

- FK_rg_DATA_rg_ALLOCATE

5. 마이그레이션을 시작한다.

* Deep Freezer, Nitrogen Tank 와 Cold Room을 분리하여 마이그레이션한다.

* 사용 프로시져

- sp_sm_MIGRATE_STORE

여기까지 아무 문제 없어야 테이블간 FK 제약조건에 위배되지 않는 마이그레이션이 수행된 것임.

★★ 2,3,4,5 의 일괄 작업을 MIGRATION_2.sql 로 실행하여 처리한다 ★★

##SL시리즈 관련 마이그레이션##

6. sl_SELL_REC, sl_SELL_DTL에 걸려있는 FK Constraint를 제거한다.

* sl_SELL_REC

- FK_sl_SELL_DTL_sl_SELL_REC

- FK_sl_SELL_HISTORY_sl_SELL_REC

* sl_SELL_DTL

- FK_sl_SELL_LINK_sl_SELL_DTL

- FK_sl_SELL_CLAIM_sl_SELL_DTL

7. SL Series Data Truncate

* sl_SELL_CLAIM -> sl_SELL_DTL -> sl_SELL_REC

8. sl_SELL_REC, sl_SELL_DTL에 걸려있던 FK Constraint를 생성한다.

9 마이그레이션을 시작한다.

* 사용 프로시져

- sp_sm_MIGRATE_SELLREC

- sp_sm_MIGRATE_SELL

- sp_sm_MIGRATE_CLAIM

여기까지 아무 문제 없어야 테이블간 FK제약조건에 위배되지 않는 마이그레이션이 수행된 것임.

★★ 6,7,8,9 의 일괄 작업을 MIGRATION_3.sql 로 실행하여 처리한다 ★★

7. 기타 테이블들 데이터 마이그레이션

* ATTRIBUTE, BACTERIA, FUNGI, ANIMAL_MAIN, PLANT_MAIN, ALGAE_MAIN2, REAGENT, PATENT

- 생성해놓은 각 테이블 별 프로시져를 이용하여 일괄 마이그레이션 한다

- ATTRIBUTE, BACTERIA, FUNGI 는 IDENTITY가 없으므로 IDENTITY_INSERT 세팅은 필요없음.

* 사용 프로시져

- sp_sm_MIGRATE_ATTRIBUTE

- sp_sm_MIGRATE_BACTERIA

- sp_sm_MIGRATE_FUNGI

- sp_sm_MIGRATE_ANIMALMAIN

- sp_sm_MIGRATE_PLANTMAIN

- sp_sm_MIGRATE_ALGAEMAIN2,

- sp_sm_MIGRATE_REAGENT

- sp_sm_MIGRATE_PATENT

★★ 10 의 일괄 작업을 MIGRATION_4.sql 로 실행하여 처리한다 ★★
