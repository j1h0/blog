[종료]개발 팁 정리· 2006.11.01.

Microsoft SQL Server 2005

드디어 Microsoft SQL Server 2005를 구매했다..

무려 소프트웨어와 익스터널 커넥터까지 해서 도합 1000만원이 훌쩍 넘는 돈을 지출했다.

연구소내에 연금을 위해서 남겨놓았던 돈까지 돌려서 구매를 하다보니...

아래층 박사님들, 및 기사님들 시선이 여간 까칠한게 아니다. -ㅂ-)r

그래도 어쩌겠느냐~ 지금까지 라이센스도 없는 데이터베이스를 누가 사용하라던가.... ㅋㅋㅋㅋ

2005의 설치는 언듯 예전, 오라클9i를 윈도우에 설치할때의 모습과 비슷하다고 생각이 들었다.

요즘 인스톨 쉴드의 트렌드가 아닌가 싶다

2005의 주요 개발 툴인 SQL Server Management Studio....

첫 만남은..... 꽤 괜찮은 놈이라고 생각이 든다...

기존에 EM의 기능과 QA의 기능을 이 SQL Server Management Studio에서 모두 가능하다는 사실이다.

즉, 스키마 디자인과 쿼리프로그래밍기능을 모두 할 수 있다는 것이다.

외형은 기존의 MS Visual Stodio 삘로 간듯 하다...

결국 Microsoft의 VS.NET이 출시되면서 Studio시리즈중 하나라는 생각을 떨쳐버릴수 없게 한다.

그 모습을 보라.. ㅋㅋㅋㅋ

위 스샷은 속성창을 닫아놓은 것이다. 속성창을 열면 기존 VS.Net처럼 오른쪽에 속성설정창이 독킹된다.

기존의 클라이언트 네트웍 유틸리티니 그 외 기타 구성 설정은 비슷한 유형으로 간다.

SQL Server Configuration Manager라는 MMC를 이용하여 구성하게 된다..

아직 서버자체의 성능 시험이나 쿼리 프로그래밍시 코드 어시스트 및 기타 기능들에 대한 경험은 해보지 못했다.

아무튼 첫만남은 괜찮다 ㅋㅋ
