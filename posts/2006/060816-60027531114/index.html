DataSource :: 연결한 SQLSever 인스턴스 이름

속성부분

CommandText :: 실행한SQL 쿼리문이나 저장프로시저

CommandTimeOut :: 데이터베이스 명령 실행 대기시간

CommandType :: CommandText 타입지정(쿼리, 저장프로시저, 테이블)

Parameters :: 쿼리문이나 저장 프로시저에 사용할 매개변수가 포함된 ParameterCollection가져옴

Transaction :: 트랜잭션 처리속성

Connection :: 연겨로디어 있는 Connection 인스턴스

메소드부분

CreateParameter :: Parameter 생성

Prepare :: 데이터베이스 캐쉬에 쿼리문 저장

Close :: 종료

Cancle :: 실행중인 명령 취소

ExecuteNonQuery :: 데이터 명령수행(내용변경시)

ExecuteReader :: 데이터 레코드를 Reader 개체로 읽어옴

ExectueScalar :: 쿼리문의 첫번째 열을 반환(반환값이 하나일때, Object 형으로 반환됨)

ReSetCommandTimeout :: CommandTimeout 프로퍼티를 30초로 재설정

[DataReader 클래스]

속성부분

FieldCount :: 현재 레코드의 칼럼 수 반환

IsClosed :: DataReader 개체가 닫혀 있는지 반환

RecordsAffected ::데이터 조작시 데이터베이스에서 바뀐 레코드 수 반환

Item :: DataReader 개체의 반환된 필드를 지정하는 배열

메소드부분

Read :: 레코드 커서를 다음레코드로 이동 (이동실패시 false)

NextResult :: 여러개의 레코드 셋에서 다음 레코드 셋으로 이동

GetName :: 레코드 셋으 필드 이름을 반환

GetOrdinal :: 레코드 셋의 필수 서수 값 반환(필드 순번)

GetValue :: 특정 필드의 값을 출력

GetXXX :: 레코드 셍의 데이터를 XXX(다양한 데이터)함수를 이용해 가져옴
