작성자 석이(minsouk) 작성일 2005-10-23 21:48:31 조회수 220

조인및 각 연산을 위해서 파일 사이즈를 적당히 늘여 주는 것이 좋다

==============================================================================

use tempdb
go

sp_helpfile
go

alter database tempdb
modify file
(name=tempdev, size=200mb)
go

alter database tempdb
modify file
(name=templog, size=200mb)
go

-- 다시 줄이고자 한다면
sp_helpfile tempdev
dbcc shrinkdatabase (tempdb,10)
dbcc shrinkfile (tempdev, 1)

=========================================================================
