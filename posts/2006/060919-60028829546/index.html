[델파이] 리소스 파일을 이용하여 WAV파일을 실행파일에 내장시키기

WAVE.RC의 내용(BRCC32.EXE를 이용 WAVE.RES로 만든다)

WAVE1 RCDATA "1.WAV"
WAVE2 RCDATA "2.WAV"

소스에 '{$R WAVE.RES}' 를 포함한다.

function TM.playWavSound(WavResName: String): Boolean;
var
ResStream: TResourceStream;
FSound: Pointer;
begin
WavResName := Trim(WavResName);
if Length(WavResName) > 0 then begin
ResStream := TResourceStream.Create(Hinstance, WavResName, RT_RCDATA);
FSound := AllocMem(ResStream.Size);
ResStream.Read(FSound^, ResStream.Size);
Result := PlaySound(FSound, 0, SND_ASYNC or SND_MEMORY or SND_NODEFAULT);
ResStream.Free;
end else begin
Result := false;
end;
end;
